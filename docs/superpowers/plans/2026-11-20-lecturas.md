# Lecturas del domingo — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Traer las lecturas de una misa desde la página pública de Iglesia.cl, guardarlas, leerlas a pantalla completa desde la misa y la ejecución, y mostrar un «por qué» opcional en las sugerencias del coro.

**Architecture:** Una tabla `misa_lectura` guarda las partes por misa. Un importador server-side pide `eucaristiadiaria.cl/dia_cal.php?fecha=AAAA-MM-DD` y un motor puro extrae las partes del HTML; el director confirma y una RPC atómica guarda. Una capa `<dialog>` a pantalla completa, alimentada por props (sin red al abrir), se abre desde la misa y desde la ejecución. Las sugerencias guardan una nota opcional y ven las lecturas de la misa elegida.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Supabase (Postgres + RLS + RPC), zod, cheerio (parseo server-side), vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-lecturas-design.md`

## Global Constraints

- RLS activa en la misma migración que crea `misa_lectura`; los casos nuevos van a `supabase/seed/verificar-rls.ts`.
- Motores puros en `lib/motores/` con tests; la UI y las consultas se verifican corriendo la app a 360 px.
- Sin IA dentro del producto (PRD §16): el texto se trae de la fuente pública o se pega a mano.
- La importación cubre solo la forma ordinaria (primera, salmo, segunda, evangelio). Días con varios formularios, secuencia o vigilia: `complejo`, no se importan, se pegan a mano.
- Texto privado: vive en la base del coro; nunca se versiona texto real del leccionario. Fixtures del repo: HTML sintético con la misma estructura.
- Atribución visible: «Fuente: Iglesia.cl · Eucaristía Diaria (Arzobispado de Santiago)».
- Una misa sin fecha no importa; el editor ofrece un campo de fecha solo para la importación.
- Reimportar pide confirmación y reemplaza las cuatro partes en una transacción; un parseo parcial no escribe nada.
- La nota de sugerencia solo existe con `misa_id` (check en la base) y máx. 280 caracteres.
- Todo en español, tuteo, tokens y 44 px de DESIGN.md.

## Review Focus

- **Día complejo (Navidad, Vigilia, secuencia)**: el importador debe devolver `complejo` y no escribir nada; un parser que agarre el primer formulario guardaría lecturas equivocadas. Test en la tarea 3; mensaje en la 6.
- **Página sin datos o de otra fecha (2027, fecha mal tipeada)**: no debe guardar vacío ni lecturas de otro día. Tests en la 3 y 4; mensaje en la 6.
- **Reimportar sobre texto corregido a mano**: solo escribe tras confirmar, y la RPC reemplaza las cuatro partes en una transacción. Verificación en la 6; RPC en la 1.
- **Lector sin red**: la capa recibe las partes por props y no hace fetch al abrir; se verifica con la página cargada y la red desactivada. Tarea 6.
- **RLS y nota**: un miembro no escribe lecturas; un ajeno no las ve; una sugerencia general no lleva nota. Casos en la 1; test del motor de sugerencias en la 8.

```sql
create table public.misa_lectura (
  id uuid primary key default gen_random_uuid(),
  misa_id uuid not null,
  coro_id uuid not null,
  tipo text not null check (tipo in ('primera','salmo','segunda','evangelio')),
  referencia text not null default '',
  texto text not null default '',
  fuente text not null default 'manual' check (fuente in ('iglesia.cl','manual')),
  fuente_url text,
  traido_en timestamptz,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  unique (misa_id, tipo),
  unique (id, coro_id),
  foreign key (misa_id, coro_id) references public.misas (id, coro_id) on delete cascade
);

create index if not exists misa_lectura_coro_idx on public.misa_lectura (coro_id);

alter table public.misa_lectura enable row level security;

create policy misa_lectura_select on public.misa_lectura
  for select using (public.puede_ver_coro(coro_id));

create policy misa_lectura_write on public.misa_lectura
  for all using (public.es_director_de(coro_id))
          with check (public.es_director_de(coro_id));

alter table public.sugerencia add column if not exists nota text;
alter table public.sugerencia add constraint sugerencia_nota_check
  check (nota is null or (misa_id is not null and char_length(nota) <= 280));

create or replace function public.guardar_lecturas(p_misa_id uuid, p_partes jsonb)
returns void language plpgsql security invoker set search_path = public as $$
declare v_coro uuid;
begin
  select coro_id into v_coro from public.misas where id = p_misa_id;
  if v_coro is null then raise exception 'La misa no existe'; end if;
  if not public.es_director_de(v_coro) then raise exception 'No tienes permiso'; end if;

  delete from public.misa_lectura
   where misa_id = p_misa_id
     and tipo not in (
       select x.tipo from jsonb_to_recordset(p_partes) as x(tipo text, texto text)
        where nullif(btrim(x.texto), '') is not null
     );

  insert into public.misa_lectura
    (misa_id, coro_id, tipo, referencia, texto, fuente, fuente_url, traido_en, updated_at)
  select p_misa_id, v_coro, x.tipo, coalesce(x.referencia,''), x.texto,
         coalesce(x.fuente,'manual'), x.fuente_url, x.traido_en, now()
    from jsonb_to_recordset(p_partes) as x(
      tipo text, referencia text, texto text, fuente text, fuente_url text, traido_en timestamptz
    )
   where nullif(btrim(x.texto), '') is not null
  on conflict (misa_id, tipo) do update set
    referencia = excluded.referencia, texto = excluded.texto, fuente = excluded.fuente,
    fuente_url = excluded.fuente_url, traido_en = excluded.traido_en, updated_at = now();
end;
$$;

grant execute on function public.guardar_lecturas(uuid, jsonb) to authenticated;
```
